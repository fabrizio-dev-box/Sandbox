# Sandbox
## barra-sessione (Mod di Claude Code)

Riga di stato in italiano sopra la casella dei messaggi (cache, contesto, limiti 5 ore/settimana, token e costo a prezzi API, pulsanti Handoff e Replay) e comandi `/token` e `/handoff`. La barra compare dove Claude Code disegna la fascia sopra il prompt (terminale, sessioni locali dell'app desktop); in una sessione cloud aperta dall'app restano i due comandi.

Installazione, al prompt di Claude Code:

```
/plugin install barra-sessione --marketplace fabrizio-dev-box/Sandbox
```

Da una shell:

```
claude plugin install barra-sessione --marketplace fabrizio-dev-box/Sandbox
```
